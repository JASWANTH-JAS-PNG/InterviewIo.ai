# InterviewIo.ai

🚀 AI-powered Mock Interview Platform

InterviewIo.ai is a web application that simulates real interview experiences using AI. It generates interview questions, evaluates answers, and provides feedback to help users improve their skills.

---

## ✨ Features

- AI-generated mock interview questions
- Smart answer evaluation
- Performance feedback and scoring
- Resume-based question generation (optional)
- Real-time interview simulation

---

## 🛠️ Tech Stack

- Frontend: React / Next.js
- Backend: Node.js / Express
- AI: OpenAI / Gemini API
- Database: MongoDB
- Styling: CSS / Tailwind CSS
